# Examples

Runnable examples of the public `tensors` API.

Run an example from the project root:

```powershell
python examples/higher_order_gradients.py
```

## Suggested learning order

1. `higher_order_gradients.py` — first, second, and third derivatives through scalar and matrix expressions.
2. `multilayer_perceptron.py` — a two-layer neural network trained with Adam.
